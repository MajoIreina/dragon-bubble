# 性能与画质

完整设置的第五页以及桌宠 / 托盘右键菜单的“性能与画质”可进入本页。所有选项即时应用并自动保存至 `%APPDATA%/LPPDesktopPet/preferences.json` 的 `performance` 字段。旧配置缺少此字段时采用均衡默认值；无效值单独回退，不影响大小、外观、行为和位置。

| 选项 | 范围与作用 |
| --- | --- |
| 内部渲染分辨率 | 低、中、高、超高、极致五档的正方形 3D 画布（界面不显示像素数值）；放大时至少匹配窗口实际像素，避免低分辨率放大模糊；保持正交镜头、尺寸及脚底位置一致 |
| 帧率上限 | 滑动条 24～240 FPS，或勾选“不限”；不改变按时间推进的动作和物理速度 |
| 垂直同步 | 实际帧率还受显示器刷新率限制；需要更高帧率时可关闭 |
| 画质 | 低、中、高、超高、极致五档；低隐藏短绒，中保留细节，高及以上开启方向光阴影并逐档提高阴影精度；启用环境遮蔽时也提高采样质量 |
| 抗锯齿 | 关闭、FXAA、MSAA 2× / 4× / 8×、TAA，互斥应用 |
| 环境光遮蔽 | 真实 SSAO，增强脚部、鳍根与凹陷的接触层次；增加 GPU 开销 |

快捷画质方案同样提供五档：低、中、高、超高、极致。低档采用 30 FPS / FXAA，其余采用 60 FPS；高及以上启用 SSAO，极致保留 MSAA 8× 选择（SSAO 开启时实际采用 TAA）。垂直同步默认开启，仍可逐项修改。旧配置的自定义分辨率原值继续保留；滑条显示最接近的档位，实际操作后才切换到预设值。

Windows 使用 wgpu 的 Vulkan 后端。SSAO 使用单采样深度与法线预通道；开启 SSAO 时，MSAA 自动由 TAA 执行边缘平滑，用户所选 MSAA 保留，关闭 SSAO 后恢复。三渲二始终隐藏 MicroPile 短绒几何，高画质不会重新引入绒毛噪点。

桌宠离屏渲染后按当前大小的实际像素（20%～300% 对应 64～960 像素）输出，以预乘 alpha 提交 Windows 分层窗口；不再将固定 320 像素图像在 CPU 上放大。缩小采用源像素覆盖面积积分，颜色与透明度一起过滤。帧率由 Winit 事件循环定时；启用垂直同步时，帧间隔匹配桌宠所在显示器的刷新率，并受 FPS 上限约束。像素转换缓冲区和 GDI 位图按尺寸复用，避免每帧等待刷新、分配整帧副本和重建位图。设置窗口使用 wgpu 窗口交换链。托盘使用 Rust tray-icon，角色与托盘右键均显示非阻塞圆角菜单，菜单打开期间动作和物理继续更新。

3D 外观预览与桌宠共用渲染设置；关闭设置或切换离开对应分类后，预览停止处理与渲染。2D 外观继续以图片纹理渲染，全局帧率和垂直同步有效，3D 分辨率及 SSAO 不会改变图片资源本身。

`cargo test --workspace` 验证性能配置容错和持久化；`./start.ps1 -SmokeTest` 实际切换省电、高画质（SSAO）和全部六种抗锯齿、TAA 与 SSAO 组合、20% / 117% / 200% / 300% 缩放、左右拖动、关闭 TAA 后的组件清理、预览重开和模型切换，截图位于 `work/rust-smoke-data/screenshots/performance-*.png`。冒烟不会改动正常用户配置。

TAA 使用 8 相位子像素采样、运动矢量重投影、Catmull–Rom 历史重建和邻域裁剪。历史以半精度 RGBA 保存，透明覆盖率与颜色同步积累；正交镜头使用与深度无关的像素偏移。每个相机独立持有历史，在外观、尺寸、动作或方向变化以及预览重开时清空。它主要改善运动中的细纹和边缘稳定性，默认仍为 MSAA 4×。快速运动或缺少运动矢量的半透明材质仍可能有轻微拖影，可切回 MSAA。

## Windows 全屏避让与壁纸兼容

全屏避让按桌宠所在显示器判断：前台应用的可见边界覆盖该显示器时，暂停桌宠渲染、像素回读和互动。普通最大化窗口未覆盖整块显示器时不触发。桌面宿主 `WorkerW`、`Progman`、`SHELLDLL_DefView`、任务栏及桌面宿主下的渲染子窗口均不作为全屏应用；隐藏、最小化、DWM 隐藏和不参与交互的工具 / 透明窗口也排除。不会按进程名称排除整个 Wallpaper Engine，避免影响它的正常应用窗口。

如仍发生壁纸误判，先退出桌宠，再从 PowerShell 启动诊断模式：

```powershell
& '你的安装目录/My Dragon Bubble.exe' --fullscreen-diagnostics
```

保持壁纸运行，复现桌宠消失、恢复以及正常全屏切换。记录保存在 `%APPDATA%/LPPDesktopPet/fullscreen-diagnostics.jsonl`（使用 `LPP_DATA_DIR` 时在该目录）。每条包含前台窗口 / 根窗口类名、进程名与 PID、窗口与显示器物理边界、判定原因及 `paused`，不记录窗口标题。只在采样变化时写入，单文件约 1 MiB 后轮换，最多保留当前与前一份；常规运行不开启文件记录，不保留采样历史。退出后正常启动即可关闭诊断。

诊断同时记录 [SHQueryUserNotificationState](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shqueryusernotificationstate) 的返回状态（查询失败为 `null`）。它反映整个用户会话，包含演示、独占 Direct3D 等状态，不能定位显示器，因此目前作为诊断参考，不直接决定桌宠是否隐藏。
