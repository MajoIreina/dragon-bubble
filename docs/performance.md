# 性能与画质

完整设置的第五页以及桌宠 / 托盘右键菜单的“性能与画质”可进入本页。所有选项即时应用并自动保存至 `%APPDATA%/LPPDesktopPet/preferences.json` 的 `performance` 字段。旧配置缺少此字段时采用均衡默认值；无效值单独回退，不影响大小、外观、行为和位置。

| 选项 | 范围与作用 |
| --- | --- |
| 内部渲染分辨率 | 256、384、512、768、1024、1536 的正方形 3D 画布；保持正交镜头、桌宠尺寸及脚底位置一致 |
| 帧率上限 | 24、30、60、90、120、144 FPS 或不限；不改变按时间推进的动作和物理速度 |
| 垂直同步 | 实际帧率还受显示器刷新率限制；需要更高帧率时可关闭 |
| 画质 | 低画质隐藏短绒几何并关闭阴影；标准保留完整短绒；高画质增加真实方向光阴影 |
| 抗锯齿 | 关闭、FXAA、MSAA 2× / 4× / 8×，互斥应用 |
| 环境光遮蔽 | 真实 SSAO，增强脚部、鳍根与凹陷的接触层次；增加 GPU 开销 |

省电方案为 256 / 30 FPS / 低画质 / FXAA；均衡为 512 / 60 FPS / 标准 / MSAA 4×；高画质为 1024 / 60 FPS / 高 / MSAA 4×，并开启 SSAO。三种方案默认开启垂直同步，可继续逐项修改。

Windows 默认使用 Forward+ 高级渲染，支持 SSAO 和 MSAA。引擎回退到兼容渲染、或开发时使用 `--rendering-method gl_compatibility` 时，环境光遮蔽选项明确禁用；其他支持的选项继续工作。其他平台默认保持兼容渲染。托盘使用 Godot 原生 `StatusIndicator`，不依赖外部后台程序。

3D 外观预览与桌宠共用渲染设置；关闭设置或切换离开对应分类后，预览停止处理与渲染。2D 外观继续以图片纹理渲染，全局帧率和垂直同步有效，3D 分辨率及 SSAO 不会改变图片资源本身。

`tests/test_performance.gd` 检查选项校验、持久化、分辨率与落点独立、抗锯齿互斥、短绒和阴影切换。`tests/test_tray_performance_ui.gd` 以图形模式检查实际托盘注册、快捷入口、设置页即时生效及保存，并比较同一姿态开启 / 关闭 SSAO 的真实渲染像素。运行含主程序的验证前应备份用户配置，完成后恢复。
