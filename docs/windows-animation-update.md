# Windows 动画与交互更新

仅修改根目录 Rust Windows 工作区，macOS 独立副本不受影响。

## 使用

- 行为 → 桌面窗口捕捉：将桌宠拖到普通窗口上方再松手，脚底落到可见窗口顶边。窗口移动时跟随，关闭、最小化、被遮住或走出顶边后下落。排除桌面、任务栏、隐藏窗口、工具浮层和应用自身；只使用窗口几何信息，不读取窗口内容。
- 行为 → 待机原地转圈：待机时播放完整一圈，复用模型的踏步转身动作；拖动会立即中断转圈。
- 行为 → 动作时间：调整待机、走路、跑步、自动睡眠和转圈间隔，自动保存。活动时长在设定值上下浮动 15%；转圈在待机开始 1.4 秒后首次触发，以设定间隔重复，每圈 2.6 秒。
- 右键桌宠或托盘 → 一键睡觉 / 唤醒；行为页也提供相同按钮。手动睡眠持续到唤醒、点击或拖动；空中发出睡眠指令时先落地再睡。
- 黍泡泡睡眠增加缓慢闭眼、趴低呼吸和轻微摇晃，黑色 Z 字浮起。左右眼支持独立眨眼、双眨眼、眯眼与交替眨单眼。
- 菜单、设置页面使用微软雅黑，导航和标题使用加粗字形。原生 Windows 标题栏外观仍由操作系统管理。
- 其他 → 检查更新：显示正式版本、更新说明、版本页面及匹配的 Windows 下载链接；支持项目主页、反馈和发布页。点击链接交给系统浏览器；更新不会自动安装。

## 边界与配置

300% 缩放的顶部限位改为模型可见边界，允许透明画布留白移出屏幕。继续使用物理像素处理鼠标、多屏负坐标、窗口矩形和缩放，避免混用 DPI 逻辑坐标。

配置仍在 `%APPDATA%/LPPDesktopPet/preferences.json`，新增 `behavior` 字段，旧配置自动补默认值。时间字段会校验范围。窗口捕捉每 150 毫秒刷新；最大化窗口顶边上方没有足够空间时不会强行站上去。

窗口捕捉目前支持带标题框的顶层窗口，使用可见顶边片段，不能站在应用内部的子面板上。GitHub API 超时、未发布和限流均有独立提示，发布页链接始终可用。
