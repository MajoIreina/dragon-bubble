# Rust 重建进度与验证

运行入口为 `start.ps1` / `start.cmd`，构建入口为 `build.ps1`。运行时不需要 Godot。
旧 `scripts/`、`scenes/` 和 `.gd` 测试暂作为迁移功能对照保留，未链接进 Rust 可执行文件。

## 分层

- `pet-core`：配置兼容、动作识别、桌面拓扑、运动、外观包、导入和软体计算；不依赖窗口或引擎。
- `pet-desktop`：Bevy / wgpu Vulkan、原生 Windows 桌面集成、egui 设置、动画与 GPU 软体。
- `toon.rs` / `toon.wgsl`：可选三渲二材质；外观清单指定 `render_style: "toon"`。默认黍泡泡启用。
- `temporal.rs` / `temporal.wgsl`：透明 RGBA 时域抗锯齿、运动重投影、历史重置与正交镜头采样修正。
- `layered.rs`：Windows 上 Vulkan 离屏渲染结果以预乘 BGRA 交给独立分层窗口；不依赖 Vulkan 交换链支持桌面透明。

三渲二保留原生动画、骨骼、形态目标和软体。黍泡泡的身体、脚掌、尾巴改为平整色块，保留眼睛/刺绣与角的颜色；关闭细密绒毛几何，避免小尺寸噪点。

## 验证方法

```powershell
cargo test --workspace
cargo build --workspace
./target/debug/dragon-bubble.exe --smoke-test
```

冒烟使用独立的 `work/rust-smoke-data`，等待动作和外观加载后输出透明截图，遍历八状态、全部已安装外观和二十三组渲染场景（包含 SSAO、FXAA、MSAA 2/4/8、透明 TAA、缩放、预览与外观切换），另对拖动和抛起的左右方向各检查一次 ±90° 朝向并截图。真实用户数据仍为 `%APPDATA%/LPPDesktopPet`，可用 `LPP_DATA_DIR` 隔离。

拖动时朝向跟随鼠标最近的水平移动，3 像素阈值过滤抖动，竖直移动或停住时保留方向。拖动和抛起均保持完全侧对（±90°），进入拖动时取消未完成的转身，同时保留原生 `PickedUp` 提起动画。

## 功能覆盖与验证边界

- 行为：八状态、原生动作优先、动作手动映射、程序化骨骼和眨眼/微笑回退、待机闪光、睡眠鼻息和 Z 字、转身与软体截面蒙皮已实现。黍泡泡使用 28 个软体截面，并保留专用原生动画。
- 桌面：拖拽、抛掷、落地、跨屏拓扑、屏幕热插拔找回、置顶、托盘和右键菜单已实现。负坐标、相邻屏幕、台阶、重力和热插拔有核心回归；实际多屏及混合 DPI 尚需在对应硬件上验证。
- 外观：GLB/glTF、VRM 通用网格、原生 OBJ/FBX、图片/GIF/精灵图；可选 Blender 转换 blend/STL/PLY。导入事务、路径约束、OBJ 子目录 MTL 与纹理已有回归；生成的 FBX 样本验证材质、蒙皮、形态目标和原生动画，并已运行渲染冒烟。
- 设置：独立大小面板、六类设置、搜索、实时预览、后台文件选择与导入、适配保存、已有配置兼容和中日英文案已实现。桌面已核对中文/英文即时切换及透明显示。
- 渲染：Vulkan、预乘 alpha 合成、Windows 分层窗口整帧呈现。模型句柄由实例长期持有，加载完成后才替换旧实例；切换分辨率会重建合成纹理绑定。SSAO 开启时使用单采样前处理，选中的 MSAA 由透明轮廓兼容的 TAA 替代。

当前测试通过不等于所有第三方模型与所有桌面环境均已验收。FBX 多层纹理和多段 in-between 形态目标尚未完整支持；VRM 专用表情绑定、MToon 与弹簧骨尚未实现。三渲二轮廓采用视角法线暗线，并非屏幕等宽描边。设置界面采用 egui 实现 Win11 风格分类导航和设置卡片，启动时匹配系统深浅色；未复刻旧 Fluent 过渡动画。

Windows 透明窗口采用 GPU 回读与原生分层合成，存在回读和 CPU 颜色编码转换成本；输出按实际窗口大小生成（64～960 像素），去除固定 320×320 图像二次放大，正确剥离 GPU 行对齐填充。内部 3D 分辨率可以调节，放大时至少匹配窗口像素。其他操作系统的透明呈现未验收。

## 导入验证工具

```powershell
cargo run -p pet-core --example import -- work/rust-smoke-data path/to/model.fbx path/to/model.obj
cargo test -p pet-core --test native_models -- --include-ignored
```

第二条命令的 FBX 回归需要先按 `tests/create_blender_fixtures.py` 生成样本。自动化截图位于 `work/rust-smoke-data/screenshots/`，构建产物位于 `outputs/rust/`。

## 悬挂交互与设置外观

`pet-core::interaction::Suspension` 在未缩放的桌面坐标中计算速度滤波、阻尼摆动、拉伸与位移滞后。抓取点作为变形支点，水平方向仍保持侧对；黍泡泡四只脚以错开的相位蹬动，移动越快动作越明显，松手后逐渐恢复原生动作。`pet-desktop::suspension` 在原生动画之后、变换传播之前应用脚部叠加；每帧先还原，避免累计漂移。软体在自由落体时卸载支撑压缩，提起后尾腹下垂。

三渲二通过独立材质参数控制明暗分段、过渡宽度和轮廓柔度；减弱 AO 与高光反差，保持色块风格。设置窗口采用 Win11 风格侧栏、圆角卡片、蓝色选中标记，跟随系统深浅色，并统一使用黍泡泡 LOGO（窗口标题与侧栏）。渲染分辨率和帧率改为滑动条，保留即时应用、自动保存与不限帧率。

## 设置导航与更新

`ui.rs` 维护共用布局和组件，`ui/pages.rs` 实现六个分类页面；通用设置卡片在窄窗口中将控件移至说明下方，侧栏底部按钮纵向排列。顶部搜索返回包含其他页的匹配分类，导航保持固定。语言设置移至“其他”，保留即时切换和自动保存。渲染冒烟覆盖六页、中日英“其他”页，以及 760×560 的日文“其他”和英文性能页。

`updates.rs` 只在点击检查时，通过 HTTPS 后台查询固定项目的 GitHub Releases API，设置 15 秒超时与 256 KiB 响应上限，按 SemVer 比较正式版本。404 显示暂无公开发布，403 / 429 显示服务暂时受限，网络或无效响应显示检查失败。提供固定项目发布页链接；不会自动下载、安装或替换程序。版本号来自 Cargo 包元数据。
