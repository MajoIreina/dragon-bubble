# 龙泡泡 v0.1.1 · Windows

本次发布更新 Rust Windows 桌宠的动画、窗口交互和设置体验。

## 下载与运行

下载 `dragon-bubble-v0.1.1-windows-x64.zip`，完整解压后运行 `My Dragon Bubble.exe`。请保留同目录的 `assets`、`skins`、`i18n`、`converters` 等资源，不要只移动 EXE。需要支持 Vulkan 的 Windows x64 电脑及显卡驱动。

已有设置会自动保留，新选项使用默认值。升级前请从托盘退出旧版，再解压新版到独立目录。

## 新增与优化

- 桌面窗口捕捉：可落在普通窗口的可见顶边，随窗口移动；窗口关闭、最小化、被遮挡或走出顶边后自然下落。
- 待机原地转圈，可在“行为”设置中开关和调整间隔。
- 待机、走路、跑步和自动睡眠时长可调整并保存。
- 更生动的睡眠呼吸、缓慢闭眼与黑色浮动 Z 字。
- 左右眼独立眨眼、连续眨眼、眯眼和交替单眼表情。
- 右键桌宠、托盘菜单和行为页新增“一键睡觉 / 唤醒”。
- 设置页面和快捷菜单使用微软雅黑，导航与标题适当加粗。
- 完善 GitHub 更新检查、项目主页、反馈入口、版本说明及 Windows 下载链接；更新由用户下载，不自动安装。

## 修复

- 修复 300% 放大时透明画布留白阻止桌宠拖至屏幕顶部的问题。
- 修复 GitHub 链接显示后无法打开的问题。
- 修复加粗字体首帧加载问题，确保首次打开设置窗口稳定。

## 验证与范围

31 项单元 / 回归测试通过；1 项既有 Blender FBX fixture 测试跳过。Clippy 检查通过，Vulkan 渲染验证覆盖 8 种状态、7 个已安装外观、23 组画质参数及 4 组左右朝向。

窗口捕捉针对普通顶层窗口，不包含应用内部子面板；上方空间不足的最大化窗口不会强行站立。GitHub API 限流时可使用发布页入口。本次二进制发布仅提供 Windows x64。
