# 龙泡泡 v0.1.2 · Windows

## 动画与互动

- 尾巴增加独立阻尼响应：落地立即下垂，再轻微回弹收稳；黍泡泡的后段软体更快恢复承托。保留原生动作的左右摆尾。
- 待机原地转圈从四个脚掌的位置计算旋转轴，避免长尾巴拉偏模型中心而产生绕圈位移。
- 点击新增四种反馈，依次切换：挤眼张嘴、开心笑眼、惊讶、俏皮单眼。挤眼与粉色张嘴参考用户提供的表情图，表情几何贴合模型脸部曲面。
- 连续点击可立即重触发表情和互动动作，结束后平滑恢复原有面部表情；睡觉、拖拽等动作可打断点击表情。

## 构建

版本号为 0.1.2。`./build.ps1` 生成 `outputs/rust/My Dragon Bubble.exe`，黍泡泡模型继续内嵌 EXE。源码仓库不包含角色模型，其他示例角色保持移除。

## 验证

41 项单元 / 回归测试通过，1 项需要 Blender 样本的既有测试跳过。带内嵌模型和不带模型的构建均通过 Clippy（`-D warnings`）。渲染冒烟覆盖 8 种动作状态、23 组画质参数、左右朝向和 4 种新表情。速度侧向、拖拽停住转正、恢复移动和轻微抖动的回归覆盖 30 / 60 / 144 FPS、20% / 100% / 300% 缩放；滚轮回归检查高精度累积、上下限、位置锚点、保存和缩放后继续拖动。完整模型继续由 EXE 内存资源加载，不释放外置模型文件。

## 连续回弹修正

尾巴响应改为读取每次物理触地事件及碰撞速度，修复角色始终处于“空中”状态时，中间回弹没有下垂反馈的问题。每次接地施加短促下压和软体承托脉冲，反弹后恢复腾空姿态；落地后水平滑动继续保持支撑，重新抓取可打断触地脉冲。

新增实际连续回弹的 GPU 检查：`cargo run --locked -p pet-desktop --features embedded-shu -- --bounce-test`，在独立测试数据目录输出每次触地和约 50 毫秒后的截图。物理回归覆盖 30 / 60 / 144 FPS 下三次连续接地，以及真实运行层到动画层的事件传递。

## 拖拽、边缘和睡眠修正

- 移除右键“调整大小”按钮及独立弹窗。鼠标悬停在角色可见区域时，滚轮向上放大、向下缩小，每格 5 个百分点，范围 20%～300%；高精度滚轮累计到一格后调整。支持未激活窗口悬停缩放，其他窗口及透明区域滚轮保持原有用途；设置中的大小滑条继续保留。
- 提起移动时，根据横向速度连续改变侧向程度：面对观看者为 0°，左侧最低 -90°，右侧最高 +90°；约 450 像素/秒对应 45°，900 像素/秒达到 90°，速度按缩放归一化并平滑过渡。停止移动后平滑转向正面，并轻微左右摇晃，全程保持悬挂动作。释放后在空中保留松手瞬间的朝向，落地后恢复后续动作。轻微手抖和贴边限位的位置调整不会频繁切换朝向，桌面布局刷新和其他动作状态不能覆盖仍在进行的拖拽。
- 左右限位使用实际渲染轮廓，允许透明画布边距移出屏幕，使角色能够贴近最左、最右边缘；适配缩放和多屏坐标。回归覆盖 20%、100%、300% 缩放及负坐标显示器。
- 移除睡眠蓝色泡泡。黑色 Z 每 7 秒出现一次，在 2.6 秒内由小变大、向上飘动并淡出，其余时间留白；每次进入睡眠重新开始计时。
