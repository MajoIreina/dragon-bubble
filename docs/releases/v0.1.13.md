# v0.1.13

- 修复 Windows 全屏检测未排除桌面宿主的问题：排除 WorkerW、Progman、桌面视图、任务栏以及桌面宿主下的渲染子窗口，避免这些窗口覆盖屏幕时触发桌宠避让。
- 排除隐藏、最小化、DWM 隐藏和不参与交互的工具 / 透明窗口，保留按桌宠所在显示器的全屏避让。
- 新增 `--fullscreen-diagnostics` 按需诊断入口，在本地记录窗口类名、根窗口、进程、边界及判定原因；日志按变化写入并限制大小，正常运行不记录历史。
- 同时记录 Windows 通知状态供实机排查，不将演示模式等全局状态直接当作当前显示器全屏。

新增桌面宿主与子窗口原生回归、全屏 / 最大化边界与显示器判定测试。Wallpaper Engine 具体窗口类型仍需结合实机诊断确认；详见[全屏诊断说明](https://github.com/MajoIreina/dragon-bubble/blob/main/docs/performance.md#windows-全屏避让与壁纸兼容)。
