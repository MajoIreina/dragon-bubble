# v0.1.6 · 更自然的桌面日常

- 修复屏幕右边缘因朝向改变而连续反向、卡住的问题。
- 自动睡眠改为持续无互动后触发，点击、拖动和滚轮缩放重新计时，睡眠持续到互动或唤醒；手动睡眠保留。
- 睡眠身体压缩限制为 3%，轻微呼吸；新增猫犬般后脚支撑、站起扒屏及交替抬爪的随机动作。
- Windows 同时提供便携 ZIP 和安装 EXE，可选择安装目录、创建快捷方式、覆盖升级和卸载，保留用户设置。
- 每天后台检测 GitHub 更新并在设置提醒；Windows 经用户确认后自动下载并校验 SHA256，沿用目录更新并重新启动。
- 设置、菜单和更新确认支持浅色、深色与实时跟随系统，安装器启动时自动适配系统主题。

Windows x64 / macOS Apple Silicon 使用同一版本与提交发布。

修复联合验证中发现的 macOS 界面系统参数检查问题。
