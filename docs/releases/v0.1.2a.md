# 龙泡泡 v0.1.2a · Windows

## 鼠标响应与帧调度

- 移除主线程逐帧等待 DWM 刷新和休眠限帧，改由 Winit 事件循环按配置帧率调度，减少输入钩子被渲染等待阻塞的时间。
- 开启垂直同步时，根据桌宠所在显示器的刷新率安排更新，并继续遵守 FPS 上限；切换显示器后定期刷新显示器参数。
- 拖动期间暂停桌面窗口枚举，避免桌面支撑检测影响鼠标移动与拖拽反馈。
- 复用分层窗口的 GDI 绘制上下文、DIB 位图和像素缓冲区；只有输出尺寸变化时才重建位图。
- 将每帧 RGBA 复制、重复色彩空间幂运算和透明边界多次扫描合并为缓冲复用、预计算查找和单次读取处理。

## 构建与验证

版本标记为 **0.1.2a**。Cargo 使用兼容 SemVer 的 `0.1.2-alpha.1` 包版本，应用界面、更新检查和 GitHub Release 使用项目版本标记 `0.1.2a`。发布版继续将黍泡泡模型内嵌于 EXE；源码仓库与 ZIP 发行包不包含独立模型或示例模型。

已验证工作区测试、Clippy（警告视为错误）、Windows MSVC 目标构建，以及 Windows 渲染冒烟测试。冒烟覆盖 8 种动作状态、23 种性能模式、朝向与交互反馈。
