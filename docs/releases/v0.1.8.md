# v0.1.8 · 全屏避让与资源优化

- 修正站起趴屏动作：以实际两只后脚为支点抬身，脚掌保持水平、前爪抬起，尾巴单独上抬，不再呈现尾巴撑地。
- 当前显示器出现前台全屏应用时自动隐藏桌宠，暂停桌宠渲染和像素回读，退出全屏后恢复；普通最大化窗口不触发，其他显示器的全屏应用不影响当前桌宠。
- 深浅主题共用字体覆盖参数，切换时复用字体图集；设置和右键菜单共享系统字体数据，避免加载多套冗余字体。
- 渲染设备采用节省内存的分配策略，减少为了吞吐量而预留的显存分配。
- 仅在外观和动作预览页面创建预览模型，离开预览页面或关闭设置后释放预览实体及其专用资源。
- 设置卡片统一为内容列宽度，固定内边距，长文本在卡片内部换行。
- 右键菜单使用微软雅黑加粗，移除外观选择，缩小宽度和行间留白。
- 新增完整资源压力检查，循环主题、菜单、页面、模型重载、缩放和画质切换，检查图像、网格、材质与动画资源是否累积，并采样 Windows 进程私有内存、工作集和句柄。

继续同时提供 Windows x64 安装 EXE、便携 ZIP、macOS Apple Silicon ZIP 与 SHA256 校验文件。
