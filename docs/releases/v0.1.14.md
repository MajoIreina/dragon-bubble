# v0.1.14

- 新增拖拽惯性：根据实际鼠标轨迹的方向、速度和加速度，让黍泡泡身体后半段直到尾鳍整段连续弯曲；上拖时向下滞后，下拖时向上抬起，急停、反向及松手后平滑回稳。
- 尾部形变从前后身交界处平滑增加，前半身保持锚定；保留落地、回弹和站立时的水平面接触反馈。
- 新增单实例限制：从不同目录、便携副本或不同数据目录重复启动时，新进程会在加载模型和渲染器之前退出；已有实例继续运行。退出或结束进程后锁自动释放。
- Windows 更新交接改为等待旧进程完全退出再运行安装器，兼容单实例锁和安装器运行检查。

新增真实模型的整段尾部形变检查、不同帧率 / 缩放与加速反向回归，以及 8 个并发原路径 / 副本启动和结束进程后的恢复验证。
