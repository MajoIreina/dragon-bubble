# v0.1.4 · Windows 与 macOS 同步更新

- 在“其他”设置页新增开机自启。Windows 使用当前用户的启动注册项，macOS 使用用户 LaunchAgent；登录启动默认隐藏设置窗口。
- 角色与托盘右键改为非阻塞圆角菜单，打开菜单时动作、睡眠和物理持续更新。菜单按内容自动调整高度，修复 Windows 透明空白被显示为黑边的问题。
- 渲染分辨率与画质均提供低、中、高、超高、极致五档，分辨率界面隐藏具体像素数值。保留旧配置中的自定义分辨率，操作档位后再应用预设。画质档位实际控制短绒、方向光阴影精度和启用环境遮蔽时的采样质量。
- 重绘六个导航图标，统一颜色和居中布局：龙泡泡、跑步人物、显示器、实心播放、互咬齿轮、省略号。
- 减轻睡眠时的纵向压缩与横向摊开，保留闭眼、趴下和呼吸效果。
- 两个平台从同一提交、同一版本和同一标签发布。新增自动版本管理工具及双平台构建成功后统一公开 Release 的流水线，详见[发版规则](https://github.com/MajoIreina/dragon-bubble/blob/main/docs/releasing.md)。

- 适配 Rust 1.99 的严格检查，统一固定长度像素与模型数据的切片处理。v0.1.3 构建验证未通过，未公开 Release；本次更新统一由 v0.1.4 提供。
