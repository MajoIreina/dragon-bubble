# v0.2.1

- 显示设置新增“任意屏幕全屏时隐藏”：启用后枚举所有屏幕上的可见全屏应用，即便失去焦点也隐藏桌宠；最小化、关闭或退出全屏后恢复。继续排除桌面宿主与 WorkerW 渲染子窗口。默认关闭，保留原先按前台应用所在屏幕避让的行为。
- 行为设置新增“低重力模式”：减少重力、空气阻力和碰撞能量损耗，抛掷后有更长滞空和更多反弹；关闭后即时恢复普通物理参数。
- 新增“定位练习”：选择目标屏幕，3 秒倒计时后开始 60 秒点击练习，每次点击后随机换位置。练习使用统一的 55% 大小，暂停自主活动与抛掷，结束后恢复原大小和位置。
- 新增统一深浅色主题的结算界面：有效点击数、平均点击速度、个人最佳与本地历史；保存最近 300 局，界面显示最近 30 局，重启后保留。
- 练习中右键可取消，修改动作相关设置、出现需要避让的全屏应用或显示器布局变化时中止；未完成局不保存为成绩。
- 本版隐藏联网排行榜与成绩上传，不联网提交成绩；保留客户端及服务端协议，后续服务就绪后再启用。
